# Barend Generator

Браузерный параметрический генератор барэнда с предпросмотром 3D и экспортом STL.

## Запуск

[Открыть BMX STREET SLIDE V0.9.0](https://grigoriyfilkoff-prog.github.io/barendgenerator/v0.9.0/)

После обновления ветки `main` GitHub Actions автоматически публикует актуальную версию на GitHub Pages. Генератор работает непосредственно в Chrome; установка не требуется.

Автономную версию также можно скачать из репозитория: `v0.9.0/BMX_STREET_SLIDE_V0.9.0_TEST.html`.

## Проверенный сценарий

- открытие автономного файла через `file://`;
- построение точной CAD-модели;
- формирование и скачивание STL;
- повторное построение после изменения параметров;
- свободное вращение и масштабирование 3D-модели.
