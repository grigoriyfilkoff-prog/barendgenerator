# BMX STREET SLIDE V0.9.0 CAD

Параметрический корпус барэнда с предпросмотром и экспортом STL в миллиметрах.

## Запуск

Откройте `BMX_STREET_SLIDE_V0.9.0_TEST.html` двойным щелчком. Автономный файл содержит зависимости и CAD-ядро; сервер и интернет не нужны.

Для модульной версии из корня проекта:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8080/v0.9.0/>. Пересборка автономной версии:

```powershell
python v0.9.0/tools/pack_standalone.py
```

Корневой `../index.html` содержит прежнюю версию V0.8.2.

## Геометрия

- Внутренняя правая **M8×1,25 длиной 8 мм**, базовый профиль 60°. Наружный диаметр 8 мм, базовый малый диаметр 6,646835 мм. Винтовые витки входят в CAD, предпросмотр и STL.
- Центр резьбы совпадает с ближайшей точкой начала прорезей: 4 мм к головке и 4 мм к лепесткам. При исходной толщине головки 8 мм начало прорезей находится на глубине 11 мм, резьба занимает глубины 7–15 мм от наружной плоскости головки.
- Вход R4 переходит в отверстие Ø10 и сужение к Ø8 перед резьбой. После резьбы — конус 90° Ø8→Ø4 длиной 2 мм и канал Ø4 до торца.
- Четыре прорези шириной 2 мм открыты в торец. Корень R1 находится в 3 мм от задней плоскости головки; длина прорезей равна длине посадки минус 3 мм. Наружные торцы лепестков имеют R2.
- Задняя наружная кромка головки имеет R1; опорная часть плоскости остаётся плоской. Передний R регулируется с ограничением по диаметру и толщине головки.
- Кольцевую выемку можно отключить; её глубина, ширина и R регулируются. Центр совпадает с началом прорезей. Исходные размеры: глубина 2 мм, ширина 2 мм, R0,5.

Базовые размеры M8 сверены с [таблицей TR Fastenings](https://www.trfastenings.com/knowledge-base/thread-geometries/metric-coarse-standard). Компенсация печати и класс посадки 6H не заданы.

`parameters.js` задаёт размеры и аналитический профиль, `cad.js` строит CAD-тело и винтовую канавку. Инструмент резьбы обрезается по границам участка длиной 8 мм. Для устойчивого пересечения прорезей с выемкой инструмент прорезей смещён на 0,005 мм к головке относительно номинального начала.

При движении ползунков обновляется предпросмотр. CAD и STL строятся по кнопке «Подготовить STL»; затем доступно «Скачать STL». Изменение размеров отменяет старый расчёт и сбрасывает подготовленный экспорт. STL использует ту же сетку, что отображается после построения CAD.

## Проверки

Автоматическая проверка пользовательского конфигуратора отключена. Полная проверка включается параметром `verify: true` в тестовом Worker.

```powershell
python v0.9.0/tests/run_browser.py
python v0.9.0/tests/run_browser.py --page tests/suite.html?case=half
python v0.9.0/tests/run_browser.py --page tests/ui.html
python v0.9.0/tests/run_browser.py --page tests/seams.html
powershell -ExecutionPolicy Bypass -File v0.9.0/tests/run_direct_file.ps1
```

Нужен установленный Chrome. Проверяются корректность CAD, одно связное тело, замкнутость сетки, ориентация, дубликаты, вырожденные и пересекающиеся треугольники, повторное чтение STL. Допуск триангуляции — 0,01 мм, угловой допуск — 0,15 рад. Линейные стыки согласуются с допуском 0,002 мм. В начале и конце резьбы стыки согласуются по известным окружностям Ø8, с проверкой координат в пределах 0,0001 мм. Удаляются только треугольники нулевых CAD-крышек, целиком находящиеся внутри известной впадины резьбы. Это не общее закрытие отверстий произвольной сетки. Число операций и отклонение исходных хорд от окружности записываются в `report.repair`.

Трассировка лучей измеряет реальные диаметры резьбы M8, профиль боковых сторон, шаг 1,25 мм и правое направление на нескольких углах и витках, включая повторно прочитанный STL. Дополнительно измеряются R1/R2, ширина прорезей, вход, конус и канал Ø4. Отрицательные проверки отклоняют открытую сетку, дублирование, перевёрнутые грани, пересечения и неверные параметры.

UI-проверки охватывают русские подписи, разные размеры окна, видимость модели при движении ползунков, скачивание STL и сброс устаревшего экспорта. Автономный файл отдельно запускается через `file://` с реальным скачиванием STL.

Результаты — `tests/*-results.json`, исходный проверенный STL — `exports/`.

## Ограничения

Геометрическая проверка не подтверждает прочность крепления или посадку напечатанного винта. Материал, калибровка принтера и пробная сборка проверяются физическим образцом. Винт не включён. При импорте STL выбирайте миллиметры.

Сканирование пересечений пропускает треугольники с общей вершиной. Проверки окна браузера не заменяют испытания на физическом Honor Magic V2.

Зависимости: Three.js 0.164.1, Replicad 0.20.5, replicad-opencascadejs 0.20.2. Лицензии и исходные ссылки — `vendor/NOTICE.md`.
